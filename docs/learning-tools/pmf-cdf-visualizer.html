PMF/CDF Visualizer

The probability mass function (PMF), \(p_X(x) = P(X = x)\), gives the probability that a discrete random variable \(X\) takes exactly the value \(x\). The cumulative distribution function (CDF), \(F_X(x) = P(X \le x)\), gives the probability that \(X\) is at most \(x\); it is the running sum of the PMF. Choose a distribution and set its parameters. The mass function and distribution function update together, and any probability you compute is highlighted in both plots.

Remember: \(X\) is a discrete random variable, so the support of its PMF is a set of integers. \(P_X(x) = 0\) for every \(x\) outside the support, including every non-integer. The CDF \(F_X(x) = P(X \le x)\), by contrast, is defined for every real \(x\). It is a step function that jumps only at the integers in the support, so \(F_X(x) = F_X(\lfloor x \rfloor)\). You can still enter non-integer values for \(a\) and \(b\). The event keeps only the integers it contains; for example, \(P(X \le 2.7) = P(X \le 2) = F_X(2)\) and \(P(X \ge 2.3) = P(X \ge 3)\).
